## 三个最容易多付钱的点

**关机不等于停止计费。** 按量付费实例停止后，GPU 和 vCPU 的费用确实停了，但系统盘和数据盘只要不释放就一直扣。很多人测试完只关机不销毁，月底收到一笔纯存储账单。正确做法是销毁实例，再单独释放挂载的数据盘。

**促销小时价和常规按量价不是一个东西。** 市面上常见的「1.2 元/小时起」「2 元/小时起」多为限时活动，有的还限制「最长 100 小时」；常规按量价则在 2.3 元到 9.6 元/小时这个区间。两者混着引用，会让预算差出三四倍。看榜单时先确认那个数字的有效期和时长上限。

**便宜 70% 的抢占式实例会被回收。** 抢占式基于闲置算力竞价，资源紧张时随时中断，最高能省七成左右。它只适合可断点续跑的离线训练，不能跑线上推理。另外这类库存随时段波动，资源充足的时候提交任务更容易拿到低价。

## 按场景决定选哪一档

跑 7B 到 13B 的推理，或者 Stable Diffusion、ComfyUI 出图：24GB 显存够，T4、A10、RTX 4090 这一档都能承载。预算敏感就选按量，跑完当天释放。

30B 到 70B 的推理：看 48GB 这一档。阿里云 L20 单卡官方定位就是「70B 以下 LLM 推理」，Vultr 的 L40S 48GB、A40 48GB 是同显存级别的选项，前者按单价算更便宜。

短时实验和模型调试：按量付费，注意任务结束要销毁实例加释放数据盘，只关机不解决问题。

7×24 对外服务：包月或包年。阿里云的包年通常在包月基础上再打八折左右；Vultr 的预留实例把 A100 PCIe 从 $2.40 压到 $1.29/GPU·小时，降幅接近一半，前提是签长期合同。

大规模离线训练：核心节点包年包月保稳定，批量任务用抢占式，模型权重和数据集放共享存储。

还有一个能省钱的地方：把 FP16 模型量化成 INT4 或 INT8，显存占用降下来，原本要 48GB 卡的模型可能 24GB 就够跑，这一档的价差每月能有两三千元。

## 下单前要确认的几件事

镜像里有没有预装 NVIDIA 驱动和 CUDA。部分公共镜像不预装，手动装驱动对新手不友好，登录后先跑 `nvidia-smi` 和 `nvcc -V` 验证，再看 `nproc`、`free -h`、`lsblk` 是否与购买配置一致。

公网带宽按固定还是按流量。对外提供图片、视频输出的接口，按流量计费很容易超支，流量大的业务直接买固定带宽更可控。

快照会不会自动续费。自动快照策略会持续生成备份并占用存储计费，设个过期时间，或者定期清。

目标地域有没有库存。48GB 以上的高端卡在部分地区长期紧张，下单前先确认能不能在你要的地域创建实例。

最后给个直接的选择规则：

- 只要跑 7B–13B 推理或出图 → 24GB 卡，按量开机，跑完销毁
- 要跑 30B–70B → 48GB 卡，长期跑选包月或预留，短期选按量
- 要 8 卡整机训练 → 先确认 H100/B200 的按需实价，别按页面标价做预算
- 想用 $300 试用金开 GPU → 先读条款，Cloud GPU 大概率不在试用范围内
